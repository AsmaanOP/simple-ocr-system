Smart Optical Character Recognition (OCR) System | Python, OpenCV, Tesseract, Tkinter
Developed a desktop application for automated document digitization, leveraging the Tesseract OCR engine to extract editable text from user uploaded images.
Engineered an image preprocessing pipeline utilizing OpenCV, applying grayscale conversion, Gaussian blurring, and Otsu's binarization thresholding to clean visual artifacts and significantly improve text extraction accuracy.
Designed an intuitive Graphical User Interface (GUI) using Tkinter and PIL for seamless file selection, dynamic image rendering, and real-time text verification.
Implemented automated file-handling protocols, allowing users to instantly export parsed data into localized .txt files for downstream processing and record-keeping.
